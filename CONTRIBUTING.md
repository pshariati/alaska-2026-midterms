# Contributing

Preserve historical fits, input hashes and source versions. Add numerical changes
under new run labels, document the solver version, and use matched observed/null
fitting budgets. Do not silently overwrite published historical results.

Keep MDS, consistency scoring, ballot interpretation and RCV transfers separate.
When modifying the numerical solver, preserve identical input profiles and
document controlled comparisons before making claims about changed results.
Do not commit individual ballot exports, credentials, server configuration,
source CVR archives or unrelated project files.

Research directions discussed for legislative races include interior winners
on separately fitted axes and conditional bounds for bullet-ballot influence.
These are planned analyses, not results in this initial code release.
