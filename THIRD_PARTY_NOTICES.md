# Attribution and source lineage

The candidate-axis approach is adapted from Mahshad Habibpourparizi's work in
the Bugs in Democracy project. The reference snapshot is
SamWangPhD/bugs-in-democracy commit `2b1e69572a32d866253170facd85abc36ef252c4`.
The exact original MDS, consistency and distribution reference files retained
under `provenance/upstream_methods/` are reference material; the
current statewide runner imports the separately adapted `analysis/shared/og_axis.py`.

The release manifest records the checksum of every copied source and whether
notebook outputs were cleared and path/import references were updated. The numerical core is unchanged; those transformations are recorded in the manifest. New sharing
documentation and the generic runner are distinct from the historical code.
No new blanket license is asserted over third-party material; consult the
upstream rights holders for reuse terms. This repository does not confer new
rights to third-party datasets, desktop runtimes, fonts or research materials.

Numerical MDS is provided by scikit-learn; this project does not claim to author
that solver. Scientific dependencies retain their own licenses. Rachel/FairVote
provided the historical statewide CSVs. Bryan/FairVote provided a separate
prospective legislative archive; no analysis of that archive is claimed here.
